# Flaky Test Tracker

Use this file to track intermittent test failures until they are fixed.

## Rules

- Any test that fails intermittently should be logged here on first occurrence.
- Include failure frequency and environment (local/CI) details.
- Link a fix issue or PR.
- Remove entry only after the test has been stable for at least 20 consecutive runs.
